# Job Portal System

A backend system for job posting and application management, built with Spring Boot.

## 🚀 Features

* User authentication (JWT)
* Job posting & management
* Job search with filters
* Apply job
* CV upload
* Email notifications

## 🛠️ Tech Stack

* Java, Spring Boot, Spring Security
* Hibernate (JPA)
* MySQL
* Maven
